Data cleaningHeart disease, week 2

Heart Disease: cleaning and preparing a dataset

Took a raw clinical dataset and turned it into two new files: a cleaned version and a version ready for machine learning. I documented the reason for every preprocessing decision in a written report.

  • 918 × 12rows and columns
  • 173impossible values fixed
  • 3new features created

Steps: inspected shape, types, missing values and duplicates. Fixed impossible zeros in Cholesterol and RestingBP. Created Age_Group, BP_Category and HR_Efficiency. Encoded categories three ways (label, one-hot, ordinal). Capped outliers using the IQR method. Scaled continuous features and dropped features with low importance.

Employee Attrition Analysis

Investigated why employees leave a manufacturing company, starting from seven plain business questions. I checked the data first, then answered each question with a chart.

ModellingHealthConnect Clinic, weeks 4 to 7

HealthConnect Clinic: predicting missed appointments

Built a model to flag patients likely to miss an appointment, so the clinic can contact them first. I compared a Logistic Regression baseline with a Random Forest, then changed the decision threshold to catch more of the real no-shows.

  • 75%of actual no-shows flagged, up from 60%
  • 0.665best F1 score
  • 12 of 18features selected

Before modelling I defined the problem: the target, the features, a patient-level split so no patient appears in both training and test data, median filling for missing values, and the risk of bias by gender and age. Recall was the main measure because missing a no-show costs the clinic more than a false alarm.

The clinic and its dataset are synthetic, supplied by the programme, so the model would need testing on real data before use.

Python · Scikit-learn · Logistic Regression · Random Forest
